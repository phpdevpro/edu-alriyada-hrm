# HRM Approval Matrix

This matrix is the operating approval reference for HRM requests before Finance/Education handoff.

| Request Type | Employee Submit | HR Review | Additional Review | Final Status Owner |
|---|---|---|---|---|
| Employee Data Update Request | Yes | HR User/HR Manager | Manager Acknowledgment, IT update as needed | HR |
| Contract Renewal Request | Yes/HR | Manager/Dept Head | HR, VP | HR |
| Leave Plan Request | Yes | Manager/Dept Head | HR monitor (optional policy gate) | HR |
| Employee Training Request | Yes | Manager/Dept Head, HR | Accounts Manager | HR + Finance |
| Company Car Request | Yes | Manager/Dept Head, HR | Accounts Manager | HR + Finance |
| Children Education Allowance Request | Yes | HR Review, HR Director | Accounts Manager | HR + Finance |
| Salary Certificate Request | Yes | Manager, HR | Document issuance | HR |
| Pre Approved Overtime Request | Yes | Manager/Dept Head, HR validation | Accounts Manager (payout cycle) | HR + Finance |
| Return From Leave Request | Yes | HR Review | Manager readiness, Occupational Health | HR |
| Remote Work Request | Yes | Manager/Dept Head, HR | - | HR |
| Permission Request | Yes | Manager/HR | - | HR |
| Employee Medical License | Yes/HR | HR review | Compliance review if needed | HR |

## Standard Routing Rule

1. Employee submits request.
2. HR validates policy and eligibility.
3. If financial impact exists, route to Accounts Manager.
4. Approved or rejected request is closed with notification.
