# HRM Handoff Boundaries

## HRM Owns

- Employee profile and lifecycle status
- HR request intake, policy validation, and first-level approval
- Jameah HR data structures and compliance fields
- Request closure integrity and audit trail

## Finance Owns (After HR Gate)

- Budget and payment validation
- Accounting impact and posting controls
- Financial approval for monetary requests

## Education Owns (After HR Gate)

- Academic instructor usage (class/schedule/advising)
- Academic assignment operations

## Integration Rule

Employee-origin requests must begin in HRM. Any money-impact or academic-impact path proceeds only after HR validation.
